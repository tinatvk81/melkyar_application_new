
# 🏠 ملک‌یار — سامانهٔ مدیریت فایل‌های ملکی (دسکتاپ چندکاربره، ابری)


> **ملک‌یار** یک سامانهٔ دسکتاپ چندکاربره برای دفاتر املاک است. مشاورها روی سیستم خودشان یک اپ سبک دارند که با HTTPS به سرور ابری وصل می‌شود؛ مدیر همه‌چیز را می‌بیند و هر مشاور فقط فایل‌های خودش را — و این قانون در سرور اعمال می‌شود، نه کلاینت. پوشش کامل چرخهٔ کار املاک: ثبت فایل (فروش/اجاره/رهن/پیش‌فروش) با عکس، تاریخ شمسی، نقشه و فوریت؛ جستجوی سریع و نمای کارتی؛ هشدار فایل تکراری؛ تطبیق خودکار فایل با درخواست مشتری‌ها همراه با اطلاع‌یه؛ پیگیری روزانه و قراردادهای رو‌به‌انقضا با هشدار خودکار؛ حسابداری پورسانت شامل معامله‌های مشارکتی دو مشاور با تقسیم درصد و رسید عکس‌دار؛ چت داخلی و چت‌بات؛ خروجی PDF (قرارداد رسمی، صورتحساب، دفتر حساب) و اکسل؛ بکاپ خودکار شبانه با دانلود توسط مدیر؛ و آپدیت خودکار برنامه برای همهٔ کاربران از خود سرور. امنیت: JWT با ابطال فوری، قفل حساب، بسته‌بودن مستندات API در عملیات، و رمز دیتابیس فقط روی سرور.


****

**ملک‌یار** یک سامانهٔ مدیریت املاک برای دفاتر املاک واقعی است:
مشاورها روی سیستم خودشان یک اپ دسکتاپ سبک دارند که با HTTPS به سرور ابری وصل می‌شود.
مدیر همه‌چیز را می‌بیند؛ هر مشاور فقط فایل‌های خودش را — و این قانون در **لایهٔ سرور** اعمال می‌شود، نه کلاینت.

**معماری:** `FastAPI + PostgreSQL` روی هاست ابری ← `PySide6 (Qt)` روی ویندوز هر کاربر.
هیچ رمز دیتابیسی روی سیستم مشاور وجود ندارد؛ همه‌چیز با JWT و HTTPS.


## ✨ قابلیت‌ها

### 🏢 مدیریت فایل‌های ملکی
- ثبت فایل با ۴ نوع معامله: **فروش / پیش‌خرید / اجاره / رهن کامل** — هر نوع با فیلدهای اختصاصی خودش
- تاریخ‌های **شمسی** (جالی‌دی) در همهٔ فرم‌ها و گزارش‌ها
- **گالری عکس** برای هر فایل (تا ۱۰ عکس در هر بار، بندانگشتی خودکار در فهرست)
- **نمای کارتی دیوارگونه** + نمای جدولی — با بج بزرگ قیمت، فوریت و شمارندهٔ عکس
- **فوریت فایل**: چک‌باکس «🔥 فوری» + تاریخ مهلت + فیلتر «فوری‌ها»
- امکانات استاندارد (آسانسور/پارکینگ) + **امکانات دلخواه چیپی**
- **هشدار فایل مشابه/تکراری** (تلفن مالک یا شهر+آدرس) — با نام مشاور ثبت‌کننده، غیرمسدودکننده
- **جستجوی زندهٔ چندستونه** با هایلایت + `Ctrl+F` + **جستجوی سراسری `Ctrl+K`** (فایل + مشتری هم‌زمان)
- فیلترهای ساختاریافته کامل (شهر، منطقه، متراژ، اتاق، قیمت، نوع ملک) + **چیپ‌های فیلتر آماده** (پیشنهاد مشاور → تأیید مدیر)
- مرتب‌سازی بر اساس تاریخ / متراژ / قیمت / تاریخ پایان قرارداد
- **مبالغ بدون سقف**: ستون‌های پول از نوع NUMERIC — ثبت مبالغ چند ده رقمی بدون خطا
- **لینک مکان** روی نقشه (Share گوگل‌مپس) + باز کردن آدرس در نقشه از ردیف فایل
- صفحه‌بندی واقعی — هیچ فایلی بی‌صدا پنهان نمی‌شود (بدون حد ۵۰۰)

### 💰 حسابداری پورسانت (فقط مدیر)
- ثبت **قولنامه** روی هر فایل با درصد پورسانت (دستی یا درصد پیش‌فرض مشاور)
- **قطعی‌کردن معامله** با گارد تأیید → فایل به بایگانی می‌رود (فروخته یا اجاره‌داده‌شده)
- **معاملهٔ مشارکتی دو مشاور** 🤝: تقسیم درصد (مثلاً ۲۵+۱۵ از ۴۰)؛ در لحظهٔ قطعی،
  سهم هر مشاور به‌عنوان رکورد مستقل در دفتر خودش ثبت می‌شود
- **پرداخت/دریافت** با تاریخ شمسی، توضیح و **عکس رسید** — به‌تفکیک مشاور در معامله‌های مشارکتی
- تب **مانده‌ها**: کارکرد − خالص پرداخت برای هر مشاور
- **دفتر حساب فردی** کامل (معامله‌ها + پرداخت‌ها + رسیدها + جمع‌ها) برای هر مشاور و خود مدیر
- **PDF ها**: صورتحساب هر معامله، ماندهٔ همه، دفتر تکی، دفتر همهٔ کاربران (یک فایل)،
  و **قرارداد قولنامهٔ رسمی** با قالب متنی قابل‌ویرایش (`contract_template.txt`)
- **خروجی اکسل معامله‌ها** (راست‌به‌چپ، هدر رنگی)

### 🙋 درخواست مشتری + تطبیق خودکار
- ثبت درخواست مشتری (نوع، شهر، منطقه، متراژ، اتاق، **سقف بودجه**)
- دکمهٔ **«فایل‌های منطبق»**: فایل‌های فعالِ وفق‌دهنده با شرایط
- **اطلاع‌یهٔ خودکار 🎯**: وقتی فایل جدیدی ثبت می‌شود و با درخواست‌های باز تطبیق دارد،
  مالک هر درخواست خودکار مطلع می‌شود — «فروشگاهی که خودش مشتری می‌آورد»
- **Pipeline مشتری**: 🆕 جدید → 📞 تماس → 🏠 بازدید → 🤝 مذاکره → ✅ معامله / ❌ منصرف
  + شمارندهٔ مراحل در داشبورد

### ✅ پیگیری روزمره و اطلاع‌یه‌ها
- کارهای روزانه با **تاریخ شمسی + ساعت**، اتصال به فایل مرتبط
- فیلترهای عقب‌افتاده / امروز / آینده / انجام‌شده
- **گزارش «فایل‌های کهنه»**: فایل‌های فعالِ بدون هیچ پیگیری در N روز اخیر
- **زنگ اطلاع‌یه هوشمند**: سررسید قراردادها، قطعی معامله، پرداخت، پیام چت،
  پیشنهاد فیلتر مشاور، و تکلیف انقضای فایل‌های قدیمی
- **هشدار خودکار فوریت‌ها هنگام ورود** (قراردادهای زیر ۷ روز)
- **اسکن فایل‌های قدیمی** توسط مدیر → تصمیم مالک فایل: انقضا یا نگه‌داشتن

### 💬 چت داخلی + چت‌بات
- گفت‌وگوی خصوصی بین کاربران (حباب‌های دو-رنگ، **آواتار رنگی هر نفر**، unread counter)
- **چت‌بات ملک‌یار**: پاسخ خودکار به سؤالات متداول — مدیر سؤال/پاسخ را از UI مدیریت می‌کند

### 🗄️ بایگانی و انقضا
- بایگانی سه‌گانه: **غیرفعال / فروخته‌شده / اجاره‌داده‌شده** — سابقهٔ مالک‌ها برای همیشه
- بازگردانی با یک کلیک
- انقضای خودکار با تصمیم خودِ مالک فایل (نه حذف بی‌صدا)

### 📊 داشبورد
- ۱۱ کارت آماری کلیک‌پذیر (مستقیم به فیلتر مربوط می‌رود)
- نمودار معامله‌های قطعی ۱۲ ماه + سهم پورسانت مشاوران
- شمارندهٔ Pipeline مشتری‌ها

### ⚙️ تجربهٔ کاربری
- **تم تیره/روشن** + **اندازهٔ فونت ۱۲–۲۴ پیکسل** (اسلایدر) — در تنظیمات، ذخیرهٔ دائمی
- راست‌به‌چپ کامل + فونت **وزیرمتن**
- Toast برای پیام‌های موفقیت (بدون کلیک OK) — مودال فقط برای خطا و تأیید
- اسپینر جداول حین دریافت داده + پیام‌های empty-state راهنما
- عرض سایدبار و فونت نمودارها با اندازهٔ فونت کاربر مقیاس می‌شود

### 🔐 امنیت
- **JWT** با انقضای ۸ ساعته + `token_version`: ریست رمز/غیرفعال‌سازی → ابطال فوری همهٔ نشست‌ها
- **قفل حساب**: ۳ رمز اشتباه مشاور = قفل ۲ دقیقه (مدیر نامحدود)
- **قفل هم‌زمان (Optimistic Locking)**: ویرایش هم‌زمان دو نفر → خطای ۴۰۹، نه رونویسی بی‌صدا
- دسترسی مشاور/مدیر در **لایهٔ سرور** اعمال می‌شود
- `/docs` و `/openapi.json` در حالت عملیاتی کاملاً بسته
- **لاگ ساختاریافته** فایل + ثبت تاریخچهٔ عملیات در دیتابیس (چه‌کسی، کی، چه‌کاری)
- رمز دیتابیس فقط روی سرور؛ کلاینت فقط JWT در RAM

### 💾 بکاپ و آپدیت
- **بکاپ JSON فشردهٔ خودکار هر شب ۰۲:۳۰** + نگهداری ۱۴ نسخهٔ آخر
- بکاپ دستی + **دانلود بکاپ** توسط مدیر از UI
- **آپدیت خودکار کلاینت‌ها**: سرور `/version` + نصب‌کننده را میزبانی می‌کند؛
  کلاینت هنگام باز شدن نسخهٔ جدید را پیشنهاد می‌دهد
- آپلود نصب‌کنندهٔ تکه‌تکه (مقاوم به شبکهٔ ناپایدار) توسط مدیر

## ☁️ استقرار سرور (Runflare / Docker)

```bash
# clone خصوصی
git clone https://github.com/tinatvk81/melkyar_application_new.git melkyar
cd melkyar

# متغیرهای محیطی (روی پنل یا .env):
#   POSTGRES_HOST / POSTGRES_PORT / POSTGRES_DB / POSTGRES_USER / POSTGRES_PASSWORD
#   SECRET_KEY  (تصادفی و طولانی)
#   DEBUG=false
#   APP_VERSION=1.5.0
#   INSTALLER_FILENAME=RealEstateApp-Setup-1.5.0.exe

docker compose up -d --build      # db + server
docker compose exec server alembic upgrade head          # جداول
docker compose exec server python scripts/init_admin.py  # مدیر اول (تعاملی)
curl https://<دامنه>/health   # {"status":"ok", ...}
```

**نکات مهم استقرار:**
- میکرو-مهاجرت استارتاپ (`ensure_columns`) ستون‌های جدید و مقادیر Enum را خودکار اضافه می‌کند
- دیسک‌های پایدار برای: `server/media` (عکس+رسید+بکاپ)، `server/static_installers`، `server/logs`
- «دسترسی از راه دور» دیتابیس **خاموش بماند** — فقط API در معرض شبکه است
- `.env` هرگز کامیت نشود

## 💻 کلاینت (ویندوز)

**از سورس (توسعه):**
```bash
cd client
python -m venv venv && venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

**نصب نهایی:** `RealEstateApp-Setup-x.y.z.exe` را از سرور دانلود و نصب کنید.
آدرس سرور در پنجرهٔ ورود ← «تنظیمات اتصال» (ذخیرهٔ دائمی در settings.json کنار exe).
آپدیت خودکار: هنگام باز شدن، نسخهٔ جدید پیشنهاد و با یک کلیک نصب می‌شود.

**ساخت نصب‌کننده:**
```bash
cd client
build_installer.bat        # PyInstaller → dist\RealEstateApp.exe
upload_installer.bat       # آپلود تکه‌تکه به هاست (نام نهایی از INSTALLER_FILENAME)
```
